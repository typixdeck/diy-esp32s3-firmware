# DIY 0.4.0 界面约定

依据用户提供的传感器、外观、小乐器三张参考图，落地到真实 1024×768 RGB565 framebuffer。图中数值只用于说明布局，不进入固件数据源。

- 顶栏保持四页：固件、树莓派、应用、设置；原生线条图标，右侧显示实际 Wi-Fi 状态与当前时间，未知时间使用缺省符号。
- 深色使用海军蓝背景、克制细边框与明亮文字；亮色使用浅底深字。选中控件使用主题色，并保留高对比文字和焦点标记。
- 固件页以连接拓扑为主，数值落在组件节点上；供电、USB/I2S、I²C 和显示颜色区分。点击供电节点展开历史曲线，未知值不画成零；连线仅说明硬件关系。
- 下角显示非实体全局量：内部 RAM/PSRAM 空闲、运行时间、检测数量。
- Pi 页展示实际在线/IP/资源状态；文件与按需截图内嵌同一页系。
- 文本输入只有字段和实体键盘提示，保留触摸确认/取消，不生成虚拟字符键盘。
- 设置分为外观、Wi-Fi、时间。外观提供语言、自定义主题色/预设色、亮暗背景；选项与实际背景保持一致。
- 小乐器使用 7 个白键、5 个叠放黑键；触摸优先命中黑键，显示实体/触摸持有状态，保留滑奏、八度、音色、音量、停止发声和输入失联处理。
- Pi、电源、音频、网络的错误/未知/受限状态仍显示真实边界。UI 变化不增加 AW/GPIO/刷写或设备控制权限。

图标由本项目 C 绘图代码实现；不依赖字体中可能缺失的图标字符，也不加入浏览器或 LVGL 运行时。
