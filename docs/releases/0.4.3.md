# 0.4.3 本地候选：ESP32 内置应用

日期：2026-10-01。此版本尚未发布、刷写或进行硬件验收，`hardware_verified=false`。

- 应用页新增计算器、日历、2048，保留 MIDI 与时钟；触摸和实体键盘可达。
- 计算器支持四则/优先级/括号/小数/错误与有界输入；日历遵循公历和已有时区，未同步不伪造今日；2048 支持正确单步合并、有效移动生成、胜利继续、结束和确认重开。
- 新应用仅使用固定大小 RAM，无外部依赖或新任务；板级配置、驱动、分区、NVS、USB 和启动流程未改变。
- 独立新写实现，未复制 C1Max/CardputerZero 的源码、资源或私有数据。许可沿用 MIT。

详细操作与限制见 [内置应用](../builtin-apps.md)。预览来自实际 C 绘图代码和合成状态，不是真机截图。验收命令、镜像大小及打包结果如下。
