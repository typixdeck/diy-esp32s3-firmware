# DIY 0.4.4 本地候选

修正树莓派状态通信和升级设置保留，保留 0.4.3 的计算器、日历、2048、MIDI 与时钟。

- 新鲜 USB CDC 状态优先，包含 IP、内存、磁盘、负载、温度、频率和运行时间；1 秒心跳。网络采样与授权检查移到独立 worker，不阻塞心跳。串口失联后回退 HTTPS，文件和截图仍使用配对 HTTPS。
- 主机服务断线后仅重开核对过的同一 by-path；每次新建会话，不重放旧控制请求。维护前由 Copilot 0.2.6 暂停原活动服务，只有确认同一端口返回运行态后才恢复。
- Wi-Fi 首次默认开启，时区首次 UTC+8。已有开关、凭据、时区、NTP、配对和主题仍由本机 NVS 保存；无个人默认凭据。
- 保存网络掉线后每轮连接仍有 25 秒上限、两次快速重试，失败后按 5/10/20/40/60 秒退避重连。认证失败不反复尝试；关闭、取消和忘记网络停止重试。自动重连不重复写入已保存凭据。
- Copilot 0.2.6 使用独立签名 v2 目录：仅兼容 DIY 源应用摘要、完整分区表一致且目标 NVS 为无设备数据的空填充时，保留 0x9000–0xEFFF 的 24 KiB NVS，校验最终写入的全部字节。未知或不兼容布局停止，不默默重置。旧客户端继续使用未改变的 v1 目录。

`full.bin` 本身仍包含 NVS 空填充，直接 esptool 全写会丢设置；不能只更新固件而继续用旧写入器就宣称保留设置。[Espressif NVS 文档](https://docs.espressif.com/projects/esp-idf/en/v5.5.3/esp32s3/api-reference/storage/nvs_flash.html) 说明配置位于专用 Flash 数据分区，本次保存不代表新增 Flash 加密。备份和有效写入镜像仅在设备私有维护目录，禁止提交。

没有改变 Flash 分区、USB 描述符、驱动、板级供电、MUX、BOOT/RESET 或硬断电逻辑。当前环境禁止 SSH 和本地 HTTPS socket bind；硬件长时间重连、真实 Wi-Fi、刷写后设置留存仍未验收，`hardware_verified=false`。宿主测试、构建和独立审查的结果记录在工作区 `artifacts/serial-config-20261001/`。
