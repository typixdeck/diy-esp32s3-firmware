# DIY 0.4.2 电量修正预发布版

参考用户提供的 [STC3117 优化](https://gitcode.com/LiJinLiJin/stc3117-fuel-gauge)，补齐初始化与满充判定。保留原有拓扑界面、Pi 共享、小乐器、Wi-Fi 和主题设置。

- 修复旧 DIY 未设置初始电量、库仑计从 0 起算的问题；完整写入原装 4.2 V 电芯 OCV/SOC 表。
- 已正常运行的计量器保留 SOC 和已有系数，避免切换主控后互相重置。
- 检测到 USB 供电及充电阶段后，4.15–4.25 V / ±100 mA 持续 30 s 才校正满充。异常、冻结、过期和总线不可达显示未知。
- 独立后台采样与 MUX 事务互斥；没有新增自动电量计软复位、充电器控制或硬件电源操作。

原装参考参数为 604070 / 2400 mAh / 4.2 V，140 mΩ 是上游参考内阻而非本机实测。自动改写容量系数的学习未启用；[实现来源、条件与限制](../battery.md)。

## 产物

- `typixdeck-diy-0.4.2-full.bin`：从 `0x0` 写入，包含引导程序、分区表、应用及字体。**完整镜像覆盖 NVS，需重新设置 Wi-Fi、配对及偏好。**
- `typixdeck-diy-0.4.2-app.bin`：仅在已核对 factory 2 MiB / font 4 MiB 兼容布局后，从 `0x10000` 写入。
- `manifest.json` / `SHA256SUMS`：地址、大小、哈希与源码提交。
- [Copilot 目录](https://github.com/typixdeck/copilot/tree/main/firmware/typixdeck-diy/0.4.2) 提供同一完整镜像；刷新固件目录后选 0.4.2。

目标仍为 TypixDeck 板载 ESP32-S3 / 8 MiB Flash / 8 MiB PSRAM，ESP-IDF 5.5.1。

本地行为检查、故障注入、ASan/UBSan 和 ESP-IDF 构建通过。**尚未刷入真机或进行完整充放电/跨主控验收，因此为预发布版，`hardware_verified=false`。** 本版不把 BATFAIL/UVLOD 故障强行改成正常百分比。0.4.1 的发布文件和哈希保持不变。
