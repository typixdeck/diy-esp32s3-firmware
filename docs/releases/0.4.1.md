# DIY 0.4.1 预发布版

包含可点击的固件拓扑、功耗历史、Pi 状态/配对只读共享、实体键盘输入、小乐器、时钟及 Wi-Fi/NTP 设置。相对 0.4.0 修正小乐器双重音量衰减、HTTPS 连接与超时处理、主题色背景和边框，增加电量计只读诊断。

## 下载与安装

- `typixdeck-diy-0.4.1-full.bin`：从 `0x0` 写入，包含 bootloader、分区表、应用、字体。**完整镜像覆盖 NVS，Wi-Fi、配对及外观设置需要重新配置。**
- `typixdeck-diy-0.4.1-app.bin`：从 `0x10000` 写入，仅限已核对 factory 2 MiB、font 4 MiB 及兼容字体的设备；不改变分区表。
- `manifest.json` / `SHA256SUMS`：大小、地址和完整性校验。产物来自源码构建，不包含设备备份或个人设置。
- [Copilot 固件目录](https://github.com/typixdeck/copilot/tree/main/firmware/typixdeck-diy/0.4.1) 分发同一完整镜像，可在 Copilot 中选择后点击“写入”。

目标为 TypixDeck 板载 ESP32-S3（8 MiB Flash / 8 MiB PSRAM），构建环境 ESP-IDF 5.5.1。树莓派只读共享服务源码、安装与本地配对说明在 [host/](../../host/README.md)。

## 验证与已知限制

本地故障注入、C ASan/UBSan、网络/协议/共享服务及原生 UI 行为检查通过；ESP-IDF 构建通过。**0.4.1 未进行真机写入与整机验收，属于预发布版。**此前 0.4.0 的短时启动与 app-only 读回结果不覆盖本版。

- 电量 0% 的问题仍在定位；本版只增加诊断，没有修改电量计校准或初始 SOC。
- 音量、首次联网、共享交互、切屏/重启恢复及长时间稳定性仍需真机复测。
- Copilot 完整备份/写入/独立回读仍待 CM4 验收；一次维护模式等待曾超时，不能把备份或启动提示视为完整刷写成功。
- 当前没有 USB NIC、动态代码加载、硬件唤醒或深度休眠；CDC 伴随服务需与 Copilot 协调串口独占。
