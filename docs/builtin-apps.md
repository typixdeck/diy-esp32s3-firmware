# ESP32 内置计算器、日历与 2048

0.4.3 候选使用原生 C framebuffer，与已有 MIDI/时钟一致。三个应用采用独立新写的纯 C 实现，没有复制 C1Max/CardputerZero 源码、资源、私人数据或增加第三方依赖；新增代码沿用本仓库 MIT 许可。游戏遵循经典 2048 规则，未引入外部游戏引擎。

应用状态保存在固定大小 RAM 结构中。无堆分配、后台任务、网络或存储 I/O；三个状态结构合计小于 256 字节（不含现有 framebuffer/字体和临时栈）。离开应用保留内存状态，设备重启清空，不写 NVS。未修改板级配置、硬件驱动、Flash 分区、供电、MUX、USB 描述符或启动逻辑。

## 操作

五个应用卡片均可触摸，或 Tab / Shift+Tab 选择后 Enter 打开。每个应用左上“返回”及 Fn+Tab 返回列表。Tab 仍可访问所有按钮；新应用中方向键由应用接管时用 Tab 移动焦点。

| 应用 | 触摸 | 实体键盘 |
| --- | --- | --- |
| 计算器 | 数字、四则、括号、小数点、C、DEL、= | 数字直接输入；Shift/Sym 符号层；Enter 计算；Backspace 删除；C 清空 |
| 日历 | `<` / `>` 翻月，`<<` / `>>` 翻年，今天 | 左右翻月，上下翻年，T 回到今天 |
| 2048 | 方向按钮、新游戏确认、取消、继续 | 方向键或 WASD 移动；R 打开重开确认；Tab 选择确认/取消后 Enter；胜利后 Enter 继续（无按钮焦点时） |

计算器的常用符号：`Shift+8` 为 `*`、`Shift+9/0` 为 `(`/`)`；`Sym+Q` 为 `/`、`Sym+T` 为 `-`、`Sym+I` 为 `+`、`Sym+D` 为 `.`、`Sym+U` 为 `=`。实体键盘字符映射与已有 Wi-Fi 输入一致。Tab 聚焦按钮后 Enter 激活该按钮；直接输入数字/符号会返回计算输入模式。

## 计算器

支持运算优先级、左结合除法/减法、括号和一元正负号；例如 `(2+.5)*4` 为 `10`。结果最多显示 12 位有效数字，浮点运算可能有舍入。计算后输入运算符接上一次结果；数字、小数点或左括号开始新表达式。退格可修改原表达式，错误后仍可清除或编辑。

表达式最多 63 字节，递归嵌套最多 16 层，超出范围、语法错误、除零和非有限结果分别提示。内部解析器接受科学记数法以支持大/小结果继续计算；界面不提供科学函数或任意代码执行。

## 日历

支持公历 1–9999 年，包括百年不闰、四百年再闰规则。月份用最多六行绘制；跨年翻月和边界按钮均受限。翻月/年时将内部日期限制到目标月份最后一天。

今天来自已有 `net_service` 的时间有效标记及 UTC 分钟偏移，与时钟页一致，支持半小时时区。没有增加自动对时请求，不处理夏令时（沿用设置页约定）。时间未同步时禁用“今天”、不显示今日高亮；首次浏览从 2000 年 1 月开始，这只是浏览起点，不代表真实日期。之后可以继续浏览，成功对时后 T / 今天返回真实本地日期。不会在后台强制跳离正在查看的月份。

## 2048

每局生成两个 2/4 方块，之后每次有效移动才生成一个 2（约 90%）或 4（约 10%）；无效移动不更新随机状态。沿移动方向先压缩再合并，每个方块每步至多合并一次；得分为合并所得方块值的累计。

首次达到 2048 显示胜利并暂停，点击继续可继续玩。棋盘已满且无相邻可合并块时显示结束。新游戏需要确认，可取消；返回列表不会重开。随机数使用时间种子与固定大小 PRNG，不提供安全用途随机性。格子用指数保存，最大指数 31，分数达到 `UINT32_MAX` 后饱和，防止整数回绕。

## 验证与预览

```sh
python3 tools/check.py
python3 tools/preview_apps.py --render-only
```

Mac 默认检查启用 ASan + UBSan。纯逻辑检查覆盖括号/优先级/错误/长度/大量畸形输入、完整公历 400 年周期/世纪闰年/时区跨午夜/未同步、2048 四方向合并/单步合并/无效移动/生成/胜利/继续/结束/重开/分数边界。实际 UI 测试覆盖五个卡片的键盘进入/返回、触摸和 Shift/Sym 输入、日历导航、WASD/方向键、确认取消、切屏输入门控、亮暗主题和按钮不重叠。

`tools/preview_apps.py` 查看由真实 `main/ui.c` 绘制的演示图片，包含错误、未对时、胜利与结束；图片本身不响应应用输入。`build/preview-ui/manifest.json` 记录渲染器摘要、实际 sanitizer 和 `hardware_verified=false`。`docs/screenshots/` 为同一演示状态的选定静态图片。

设备上仍需逐项确认触摸位置、实体矩阵键盘、长时间运行与切屏恢复；本候选未刷写，宿主测试不能替代硬件验收。
